## 다음 습관

### 모델 판단 (지표 근거)
- 실패→통과 1 / 재시도 0 → 회귀 테스트를 먼저 추가해 실패(E1)를 확인한 뒤 수정하는 순서를 유지한다. 원인 기록 1건이 이 순서에서 나왔다.
- 실행 수 1 (quick) → 표본이 작아 개선 습관을 도출하지 않는다. run이 3개 이상 쌓이면 다시 회고한다.
